# 这破相机真难用

通过交互实验学习光圈、快门和 ISO。中文单文件教程，无外部运行依赖，可离线使用。

## 内容

- 光圈、景深与对焦距离；光圈系数、孔径及整档刻度的计算。
- 快门时间、运动拖影与相机抖动。
- 收光量、ISO 增益与噪点。
- 曝光档位、等亮度补偿与 A/B 对照。
- M、A/Av、S/Tv 相机模拟。
- 四个拍摄任务、理解自测和实拍指南。

光圈、快门和 ISO 均分为“快速了解”和可展开的“详细原理”。快速部分提供单参数预览，详细部分保留公式与完整实验。

支持暂停、单步和复位。手机竖屏使用常驻章节选择与播放栏、单列控件、放大的拖动手柄，以及竖向排列的原理图和表格。图像是教学示意，公式假设、适用范围和参考资料见页面说明。

## 使用

下载后直接用浏览器打开 `index.html`。

GitHub Pages 的发布来源为 `main` 分支根目录。`.nojekyll` 用于直接发布静态文件；推送到 `main` 后会触发更新。

`outline.md` 记录课程结构与模型说明。

虚化由像素运算完成，不依赖 Canvas 滤镜支持。图层按虚化程度缓存，播放动画时复用。

回归检查：`node --test tests/blur.test.cjs`，覆盖虚化强弱、透明边缘和小尺寸图像。
